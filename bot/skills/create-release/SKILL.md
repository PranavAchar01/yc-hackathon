# Create GitHub Release

Learned by watching Achar Pranav do this once. Replay the steps in order.

## Steps

1. Open the over-the-shoulder repository on GitHub
2. Click Releases in the repository sidebar
3. Click Draft a new release
4. Open the tag picker, type v0.4.0 and choose Create new tag: v0.4.0 on publish
5. Title it v0.4.0 Live view in Slack and write two lines of notes from the recent commits
6. Click Publish release
